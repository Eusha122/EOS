# EOS Privet wallpapers

These files are the canonical source wallpapers for the ISO.

- `cicada-default.png` is the default fresh-session wallpaper, supplied as `ChatGPT Image Aug 15, 2026, 05_09_55 AM.png`.
- `cicada-01.png`, `cicada-02.png`, and `cicada-03.png` are selectable alternatives in the **EOS Wallpapers** application.

The build script copies these images into the live ISO. Do not place generated ISO files in this folder.
